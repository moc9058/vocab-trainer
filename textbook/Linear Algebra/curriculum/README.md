## 第1章 Vector Spaces（6目標）

### `la-vector-space-axioms`

ベクトル空間の公理を具体的な演算に照らして説明できる

- 主な能力：概念
- 根拠節：1.1
- 確認する解答内容：各公理が対象とする演算と量化を説明し、反例では破れる公理を特定する
- 直接の前提：カタログ内では指定なし（初等的な集合・数の演算は別途想定）
### `la-subspace-criteria`

部分空間判定の三条件の意味を説明できる

- 主な能力：概念
- 根拠節：1.2, 2.1
- 確認する解答内容：零ベクトル・加法・スカラー倍の条件を区別する
- 直接の前提：la-vector-space-axioms
### `la-subspace-decision`

具体的な集合が部分空間か理由付きで判定できる

- 主な能力：適用
- 根拠節：1.2, 2.1
- 確認する解答内容：成立時は全条件を示し、不成立時は具体的な反例を一つ示す
- 直接の前提：la-subspace-criteria
### `la-sum-smallest`

部分空間の和が各部分空間を含む最小の部分空間であることを示せる

- 主な能力：論証
- 根拠節：2.2
- 確認する解答内容：閉性、各部分空間の包含、任意の共通上位部分空間への包含を示す
- 直接の前提：la-subspace-decision
### `la-direct-sum`

分解の一意性または共通部分を使って直和を判定できる

- 主な能力：適用
- 根拠節：1.3, 2.3, 2.4
- 確認する解答内容：二つの部分空間では共通部分が零であることを確認し、和の分解と結び付ける
- 直接の前提：la-sum-smallest
### `la-direct-sum-conditions`

三つ以上の部分空間で二つずつの共通部分が零でも直和とは限らないことを説明できる

- 主な能力：論証
- 根拠節：1.3, 2.3
- 確認する解答内容：具体的な反例と零ベクトルの非自明な分解を示す
- 直接の前提：la-direct-sum

## 第2章 Finite-Dimensional Vector Spaces（6目標）

### `la-span-membership`

ベクトルが与えられたリストの張る空間に属するか判定できる

- 主な能力：適用
- 根拠節：1.1, 2.1
- 確認する解答内容：線形結合の係数を示すか存在しない理由を示す
- 直接の前提：la-subspace-decision
### `la-linear-independence`

線形独立性を判定し、従属の場合は非自明な関係を示せる

- 主な能力：適用
- 根拠節：1.4, 2.2
- 確認する解答内容：零への線形結合の係数を検討し、ベクトル数だけで結論しない
- 直接の前提：la-span-membership
### `la-basis-coordinates`

基底を判定し、その基底に関する座標を求められる

- 主な能力：適用
- 根拠節：1.5, 2.4
- 確認する解答内容：独立性と生成性を確認し、座標の存在と一意性を説明する
- 直接の前提：la-linear-independence
### `la-basis-extension`

生成リストの縮約または独立リストの拡張により基底を構成できる

- 主な能力：論証
- 根拠節：2.5, 2.6
- 確認する解答内容：操作後の生成性・独立性を説明し、有限次元性を確認する
- 直接の前提：la-basis-coordinates
### `la-dimension-sum`

部分空間の和と共通部分の次元を関係付けて求められる

- 主な能力：適用
- 根拠節：2.8, 2.9
- 確認する解答内容：共通部分を数え落とさず次元公式の各項を対応付ける
- 直接の前提：la-basis-coordinates, la-direct-sum
### `la-complement-construction`

有限次元空間で部分空間の補空間を構成できる

- 主な能力：論証
- 根拠節：2.6, 2.7
- 確認する解答内容：基底を延長して和が全空間かつ共通部分が零であることを示す
- 直接の前提：la-basis-extension, la-direct-sum

## 第3章 Linear Maps（9目標）

### `la-linear-map`

写像の線形性を判定し、基底上の値から写像を定められる

- 主な能力：概念
- 根拠節：1.1, 2.1.1
- 確認する解答内容：加法・スカラー倍の保存と基底からの線形拡張の一意性を説明する
- 直接の前提：la-basis-coordinates
### `la-kernel-range`

線形写像の核と像の基底を求められる

- 主な能力：適用
- 根拠節：1.2, 2.1.2
- 確認する解答内容：核の方程式と像の生成元を求め、独立な基底に整理する
- 直接の前提：la-linear-map, la-basis-coordinates
### `la-rank-nullity`

階数・退化次数定理を用いて単射・全射の可能性を判断できる

- 主な能力：論証
- 根拠節：2.1.3, 2.1.4, 2.1.10
- 確認する解答内容：定義域・値域の次元を区別し、有限次元仮定の下で結論する
- 直接の前提：la-kernel-range
### `la-matrix-composition`

指定された基底で写像と合成写像を行列表示できる

- 主な能力：適用
- 根拠節：1.3, 2.1.6, 2.1.13
- 確認する解答内容：列を基底ベクトルの像の座標として作り、合成の順序を守る
- 直接の前提：la-linear-map
### `la-change-basis`

基底変換による行列表現の変化を計算できる

- 主な能力：適用
- 根拠節：2.1.15
- 確認する解答内容：座標変換の向きを明記し、作用素では相似変換を用いる
- 直接の前提：la-matrix-composition
### `la-quotient-map`

商空間の元と誘導写像の定義が代表元によらないことを示せる

- 主な能力：論証
- 根拠節：1.6, 1.7, 1.8, 2.2.3, 2.2.5
- 確認する解答内容：同じ剰余類の代表元の差を使って像の一致を示す
- 直接の前提：la-linear-map, la-kernel-range
### `la-quotient-dimension`

商空間の次元と第一同型定理を具体的な写像に適用できる

- 主な能力：適用
- 根拠節：2.2.4, 2.2.5
- 確認する解答内容：商の対象を核と対応付け、同型先を像として特定する
- 直接の前提：la-quotient-map, la-rank-nullity
### `la-dual-basis`

指定された基底の双対基底と双対写像の行列を求められる

- 主な能力：適用
- 根拠節：1.9, 1.10, 1.11, 2.3.1, 2.3.6
- 確認する解答内容：双対基底の評価条件を確認し、転置と共役転置を混同しない
- 直接の前提：la-matrix-composition
### `la-annihilator`

零化空間を核・像および双対写像と関連付けられる

- 主な能力：論証
- 根拠節：1.12, 2.3.3, 2.3.4, 2.3.5
- 確認する解答内容：どの空間の双対かを明記し、次元または包含で等式を示す
- 直接の前提：la-dual-basis, la-rank-nullity

## 第4章 Polynomials（3目標）

### `la-polynomial-division`

根の個数の上限を使って多項式の同一性を示せる

- 主な能力：論証

- 確認する解答内容：差の多項式の次数と相異なる根の数を比較する
- 直接の前提：la-polynomial-division
### `la-complex-factorization`

複素数上の因数分解と実係数多項式の共役根を説明できる

- 確認する解答内容：重複度を数え、実数上と複素数上の分解可能性を区別する
- 直接の前提：la-polynomial-division

## 第5章 Eigenvalues and Eigenvectors（7目標）

### `la-eigenpairs`

固有値・固有空間を定義と核から求められる

- 主な能力：適用
- 根拠節：1.1.3, 1.1.4, 1.4.2, 2.1.1
- 確認する解答内容：非零固有ベクトルと零を含む固有空間を区別する
- 直接の前提：la-kernel-range
### `la-invariant-subspace`

部分空間の不変性と商作用素の定義可能性を確認できる

- 主な能力：論証
- 根拠節：1.1.2, 1.1.6, 2.1.3
- 確認する解答内容：像が部分空間内に残ることと代表元によらないことを示す
- 直接の前提：la-quotient-map, la-eigenpairs
### `la-minimal-polynomial`

低次元の作用素の最小多項式を求め、その最小性を説明できる

- 主な能力：適用
- 根拠節：1.1.5, 1.2.1, 2.2.2, 2.2.4
- 確認する解答内容：代入して零になるだけでなく、より低次が不可能な理由を示す
- 直接の前提：la-polynomial-division, la-matrix-composition
### `la-triangularization`

上三角表示と不変部分空間列・最小多項式の分解を結び付けられる

- 主な能力：論証
- 根拠節：2.3.1, 2.3.2, 2.3.3
- 確認する解答内容：体上での一次因子への分解可能性と対角成分の意味を説明する
- 直接の前提：la-invariant-subspace, la-minimal-polynomial, la-complex-factorization
### `la-diagonalizability`

固有空間または最小多項式を使って対角化可能性を判定できる

- 主な能力：適用
- 根拠節：2.4.1, 2.4.2, 2.4.3
- 確認する解答内容：固有空間の次元和または相異なる一次因子による判定を正しく使う
- 直接の前提：la-eigenpairs, la-minimal-polynomial, la-dimension-sum
### `la-commuting-operators`

可換作用素の共通固有ベクトルや同時対角化の条件を判断できる

- 主な能力：論証
- 根拠節：2.5.2, 2.5.3, 2.5.4
- 確認する解答内容：可換性だけで同時対角化を断定せず、対角化可能性や体の条件を確認する
- 直接の前提：la-diagonalizability, la-invariant-subspace
### `la-gershgorin`

Gershgorin円板を求め、固有値の位置を制限できる

- 主な能力：適用
- 根拠節：1.4.3, 2.4.5
- 確認する解答内容：各行の中心と半径を求め、包含による推定と厳密値を区別する
- 直接の前提：la-eigenpairs

## 第6章 Inner Product Spaces（7目標）

### `la-inner-product`

内積の条件と複素数上の共役の役割を説明できる

- 主な能力：概念
- 根拠節：1.1.1, 1.1.2, 1.1.3
- 確認する解答内容：教材の第一変数線形の規約を守り、正定値性を確認する
- 直接の前提：la-vector-space-axioms
### `la-inner-product-inequalities`

Cauchy–Schwarzの不等式と等号条件を適用できる

- 主な能力：論証
- 根拠節：2.1.1, 2.1.2, 2.1.3
- 確認する解答内容：ノルムと内積を対応付け、零ベクトルを含む等号条件を扱う
- 直接の前提：la-inner-product
### `la-gram-schmidt`

Gram–Schmidt法で同じ部分空間を張る正規直交基底を作れる

- 主な能力：適用
- 根拠節：2.2.3, 2.2.4
- 確認する解答内容：射影成分を引き、正規化と各段階の生成空間を確認する
- 直接の前提：la-inner-product, la-basis-coordinates
### `la-orthogonal-projection`

直交補空間と直交射影を求められる

- 主な能力：適用
- 根拠節：1.3.1, 1.3.2, 2.3.1, 2.3.3
- 確認する解答内容：分解の直交性と射影先を確認し、有限次元部分空間の条件を守る
- 直接の前提：la-gram-schmidt, la-direct-sum
### `la-best-approximation`

直交射影が一意な最良近似であることを説明できる

- 主な能力：論証
- 根拠節：2.3.5
- 確認する解答内容：誤差の直交分解と等号条件から最小性・一意性を示す
- 直接の前提：la-orthogonal-projection
### `la-riesz-representation`

有限次元内積空間の線形汎関数を内積で表せる

- 主な能力：適用
- 根拠節：2.2.6, 2.3.4
- 確認する解答内容：代表ベクトルを求め、複素係数の共役と一意性を確認する
- 直接の前提：la-dual-basis, la-gram-schmidt
### `la-pseudoinverse`

擬似逆を用いて最小ノルム最小二乗解を求められる

- 主な能力：適用
- 根拠節：1.3.3, 2.3.6, 2.3.7
- 確認する解答内容：残差最小と解のノルム最小を区別し、核による解の自由度を説明する
- 直接の前提：la-kernel-range, la-best-approximation

### `la-svd`
