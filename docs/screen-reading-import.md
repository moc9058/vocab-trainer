# iPhoneの画面から中国語を読み解く

小红书の投稿やコメント、财新の記事をスクリーンショットまたは選択テキストとして取り込み、Vocab Trainerで読み解けます。文章を確認すると、全体の意味、意味のまとまり、単語・文法の解説を順に読めます。学びたい項目は、その場で既存のA/Bグループへ登録できます。

文章ボタンは、Vocab Trainerに取り込んだ静止画に表示されます。小红书・财新を操作中の画面に重なるボタンではありません。画面外や未展開のコメントを取得することもできません。

## 最初にアプリを更新する

Webとbackendの配備に加えて、iPhoneのアプリも更新してください。

```bash
npm run ios:sync --prefix frontend
npm run ios:open --prefix frontend
```

Xcodeで同じPersonal Team・Bundle IDを選び、iPhoneへRunします。Googleログインや無料署名の更新は[個人用iOSガイド](ios-personal-app.md)を参照してください。Cloud Runを更新しただけでは、Shortcutsのアクションや同梱画面は更新されません。

既存アプリの最低iOSは15です。Shortcutsへ渡すアクションはiOS 16以降、コントロールセンターからの推奨手順はiOS 18以降を対象とします。

## 画像を選んで使う

1. 小红书や财新で読みたい部分を表示し、端末のボタンでスクリーンショットを撮ります。
2. Vocab Trainerで中国語を選び、「外部ソース」→「画面から読み解く」→「画像を選ぶ」を押します。
3. 画像内の文章ボタン、または下の一覧から読みたい部分を選びます。
4. 原文を確認し、誤字・不要な行・改行を修正します。同じコメントの続きが別の範囲になっている場合は、両方を選べます。
5. ソース名、文章の種類、記事リンクを必要に応じて入力し、「この文章を使う」を押します。
6. 同じ確認画面で解説の言語（現在は日本語）を確認してA/Bの登録先を選び、「解析」を押します。解析後に意味のまとまりを読み、単語や構文をタップして詳細と登録ボタンを開きます。

隣り合う別人のコメントは、同じ文章としてまとめないでください。複数範囲を選んだ場合は、画面上の順序で結合されます。文章は8,000文字までです。長い記事は段落単位で分けて取り込みます。

画像は拡大・スクロールできます。番号付きの文章ボタンが押しにくい場合は、下の一覧から選んでください。

## コントロールセンターから使う

本人のiPhoneで、次のショートカットを一度設定します。[2本のショートカットの具体的な構成と診断](shortcuts/README.md)も参照してください。撮影済みの画像をIntentへ直接渡すので、ファイルや写真を選ぶ操作は不要です。

1. Appleの「ショートカット」アプリで、新しいショートカットを作ります。
2. コントロールセンターを閉じてから「スクリーンショットを撮る」アクションを実行する順序にします。閉じる操作の提供状況や撮影タイミングはOSによって異なるため、最初に対象画面が写るか確認してください。
3. Vocab Trainerの **画像を読み解く（Read an image）** アクションを追加し、**画像（Image）** に直前のスクリーンショットを指定します。入力元は「スクリーンショットのショートカット」を選びます。撮影より先に「アプリを開く」を入れないでください。
4. iOS 18以降のコントロールセンターに「ショートカット」のコントロールを追加し、作成したショートカットを選びます。

このアクションは画像を受信してからVocab Trainerを開きます。ホーム画面にいる場合は取り込み画面へ進みます。クイズ中や別の記事の編集中は、受信のお知らせから開けます。未同期の回答がある場合は、同期が完了してから開いてください。

コントロールセンター自体が写る場合は、端末のボタンで撮影し、その画像を共有シートに表示したショートカットへ渡すか、アプリ内の「画像を選ぶ」を使ってください。コントロールセンターからの撮影が本人の端末で安定して動くことは、実機での確認が必要です。

## 财新などの選択テキストを渡す

テキストを共有できる場合は、画像よりも誤認識を避けられます。共有シートから起動するショートカットを作り、Vocab Trainerの **選択した文章を読み解く（Read selected text）** の **文章（Text）** に共有入力を渡してください。

コントロールセンターの文章用ショートカットには、共有入力・対応アプリの画面入力を渡します。文章が渡されない場合は、「コピーした文章を使う」を明示的に選び、コピー済みの内容を受信Intentへ渡してください。文章を選択しただけではコピーされず、任意アプリの選択範囲を取得できる保証もありません。

新しい **読み解く文章を入力（Open reading input）** アクションは、本文なしで案内と貼り付け欄を開きます。アプリ起動時にClipboardを自動では読みません。共有内容がURLだけの場合も、この入力画面へ進みます。HTTPSリンクは出典の候補とし、本文やコメントは取得しません。

受信したテキストは原文を確認し、同じ画面で日本語の解説と登録先を確認して解析できます。出典名の既定は空です。小红书・财新以外のアプリでも利用できます。

## 意味のまとまりから詳しく読む

文の解説では、次の順に表示します。

1. この文が言いたいこと
2. 意味のまとまりごとの原文・意味・役割
3. まとまり同士のつながり
4. 文の骨格、前後との関係、ニュアンス

意味のまとまり内の単語をタップすると、その出現に対応する読み・意味・登録ボタンを開きます。複数のまとまりに関係する構文は、その旨を表示し、構文全体の説明を開きます。

保存済みの解説に意味のまとまりがない場合は、「意味のまとまりを追加」で文の解説を更新できます。以前の候補、登録結果、グループ所属は保持します。原文の誤認識を解析後に直したい場合は、取り込んだ画像で「この範囲から別のソースを作る」を選んでください。以前のソースと辞書項目は残ります。

初回解析の単語・文法抽出は従来の処理を使います。表示は意味から詳細へ進みますが、意味のまとまりを先に生成してから単語抽出を始める処理には変更していません。

## 保存、通信断、画像の破棄

「解析」を押すと、確認済みの文章を外部ソースとしてFirestoreへ保存します。単語・文法の辞書登録は、その後にA/Bボタンで行います。画像を選んだだけでは辞書には追加されません。

ソース作成に失敗したように見えても、同じ操作の再試行は同じ取り込みIDを使います。受信箱の「保存済みソースを開く・再試行」から続けてください。別の本文へ変える場合は、新しいソースを明示的に作成します。

初回解析は既存のサーバージョブで続きます。文の詳細解説は、結果をアプリで受け取って保存する方式です。詳細解説の生成中は、保存完了を確認してから閉じてください。保存済みの外部ソースは、元画像がなくても通常の一覧から開けます。

画像、未確定のOCR、未送信テキスト、範囲選択・出典・登録先・解説言語の下書き、再送用の要求は、端末内の一時受信箱に保持します。編集は約0.3秒後に保存し、画面を閉じる際も保存します。OSが保存前に強制終了した場合、最後の保存後の入力は失われることがあります。入力なしの起動要求も端末内に保持し、本文と区別します。上限は10件・合計100MiB、画像は一件20MiB・2,000万画素です。入力は24時間経過後から利用できなくなり、次回の起動・受信・操作時に削除されます。OSが指定時刻に物理削除する保証はありません。

「入力を破棄」やログアウト時の確認で、一時データを削除できます。保存済みの外部ソース、登録済みの単語・文法、学習履歴には影響しません。画像は写真ライブラリやCloudへ自動保存しません。OCRは端末内で行い、確認済み本文と出典情報だけを解析のために送信します。

## 実装と検証の境界

実装対象は、App Intentsによる受信、一時受信箱、画像選択、Vision OCR、原文確認、既存解析ジョブとの接続、意味単位の表示、既存A/B登録、取り込みの再試行です。

本人のiPhoneでのControl Center撮影、小红书・财新の実画面、Personal Teamでの新しいIntentの実行、OSごとの共有・ロック挙動は、実機確認が必要です。Simulatorや合成画像の成功で代用しません。検証結果は[iOS検証記録](ios-verification.md)へ追記します。

前回の設計の背景と後段の範囲は[初版の実装計画](../plan/ios-screen-reading-import-design.md)、解説修正・候補変換は[外部ソースの修正と読解支援](source-revisions.md)を参照してください。
